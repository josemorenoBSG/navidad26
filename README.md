# Guía Operación Navidad Tiendas

Página estática con los procesos clave de tienda para la temporada navideña: atención al cliente, tesorería, seguridad, sistemas, mantenimiento, operación en piso, capacitación, atención a inspecciones y directorio.

## Estructura

```
index.html                     Página completa (estilos, scripts e imágenes incluidos)
video/onboarding-tiendas.mp4   Video de inducción (se abre desde Capacitación)
README.md                      Este archivo
```

`index.html` y la carpeta `video/` deben subirse juntos y conservar esta estructura. Solo se cargan desde internet las fuentes de Google Fonts.

## Ver en local

Abre `index.html` con doble clic en cualquier navegador.

## Publicar

Sirve la carpeta tal cual en cualquier hosting estático (GitHub Pages, Netlify, Vercel, etc.). En GitHub Pages: *Settings → Pages → Deploy from a branch → `main` / root*.
